# Ordena

Aplicação para organização de tarefas em grupo (PWA mobile-first).

## Começando

```bash
cp .env.example .env
npm install
npm run dev          # sobe o Postgres, aplica migrations e abre http://localhost:3000 (teste: /api/v1/status)
```

Veja `AGENTS.md` (regras e comandos) e `docs/arquitetura.md`.
